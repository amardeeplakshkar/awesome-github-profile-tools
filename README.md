# awesome-github-profile-tools
> Tools to make a great GitHub profile. Curated, simple, and free to use — one line per entry.
- [github-readme-stats](https://github.com/anuraghazra/github-readme-stats) — Stats, streaks and top languages as images
- [github-profile-trophy](https://github.com/ryo-ma/github-profile-trophy) — Trophy case for your achievements
- [Shields.io](https://shields.io/) — Clean badges for tech, socials and more
- [Visitor Badge](https://visitorbadge.io/) — A simple profile view counter
- [Readme Typing SVG](https://github.com/DenverCoder1/readme-typing-svg) — Animated typing effect, no code needed
- [Snake animation](https://github.com/Platane/snk) — The contribution-graph snake everyone copies
