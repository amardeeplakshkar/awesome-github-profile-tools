> Tools to make a great GitHub profile. Curated, simple, and free to use - one line per entry.

## Why This List
Developers love showing off their profile - and every tool they add links back to lists like this. It's self-spreading: your readers become your promoters. Very low upkeep.

## Stats and Cards
| Tool | What it does |
| --- | --- |
| [github-readme-stats](https://github.com/anuraghazra/github-readme-stats) | Stats, streaks and top languages as images |
| [github-profile-trophy](https://github.com/ryo-ma/github-profile-trophy) | Trophy case for your achievements |
| [github-readme-streak-stats](https://github.com/DenverCoder1/github-readme-streak-stats) | Show contribution streak and total contributions |
| [github-readme-activity-graph](https://github.com/Ashutosh00710/github-readme-activity-graph) | Contribution timeline as area graph |
| [github-profile-summary-cards](https://github.com/vn7n24fzkq/github-profile-summary-cards) | Summary cards for profile details |
| [waka-readme](https://github.com/athul/waka-readme) | WakaTime coding stats via Action |
| [GitHub Readme StackOverflow](https://github.com/omidnikrah/github-readme-stackoverflow) | StackOverflow status on your README |
| [GitHub Readme YouTube Stats](https://github.com/DenverCoder1/github-readme-youtube-stats) | YouTube subscriber and view badges |

## Contributing
See CONTRIBUTING.md. The short version: fork this repo, add your entry as one line in the right table, open a pull request. Rules: the tool must work on a GitHub profile README and be free to use. One entry per tool.
